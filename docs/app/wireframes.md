# App 草图(Wireframes)

> 所有草图采用 ASCII 风格,**375x667(iPhone 8 基线)**。可直接给设计师重画,或前端用
> mock 工具转成高保真原型。

## 全局框架

### 主框架(4 Tab)

```
┌─────────────────────────────────┐
│  Status Bar (系统状态栏)          │
├─────────────────────────────────┤
│                                 │
│         Page Content            │
│         (当前 Tab 页面)          │
│                                 │
│                                 │
│                                 │
├─────────────────────────────────┤
│  🏠    📨    📋    👤           │
│  工作台 消息  应用   我的         │
└─────────────────────────────────┘
```

### 顶部导航模式

App 1.0 采用 **顶部单行返回 + 标题 + 操作** 模式:

```
┌─────────────────────────────────┐
│ ‹  标题              ⋯         │
├─────────────────────────────────┤
```
